# Card Brand Icons

支付卡 / 卡组织品牌图标 SVG 集合，供 atomcheck 项目使用。

## 目录

- `regional/` — 13 个地区/小众卡组织（白底横向 logo，120×80）
- `datatrans/` — 19 个信用卡品牌（来自 datatrans/payment-logos，CC-BY-SA-4.0）
- `aaronfagan/` — 17 个卡片图标（来自 aaronfagan/svg-credit-card-payment-icons，flat-rounded 风格）

## regional/ 来源

| 品牌 | 来源 |
|---|---|
| uatp / dankort / rupay / vpay / paypal | datatrans |
| verve | Wikimedia（2024 官方版） |
| girocard / bankcard / belkart / meeza / pagobancomat | Wikimedia |
| cmi / cabal | worldvectorlogo |

## 说明

- 图标均为各卡组织商标，仅作技术展示用，请遵守各品牌的使用规范。
- 地区品牌的横向 logo 采用 120×80 比例（含白底），适合在白色背景上展示。
